# ali-email-zhuizong (外贸企业邮箱邮件已读追踪助手)

一套 100% 属于你自己的、完全免费的外贸企业邮箱已读追踪系统（支持**阿里企业邮箱**、**网易企业邮箱**及 **Gmail**），彻底告别小满 OKKI、Apollo 等商业平台昂贵的年费绑定。

---

## 核心特性

- 🎯 **行内无缝集成**：直接在阿里/网易邮箱“已发送”列表行内渲染状态标签（`✓✓ 已读 9次 · 日本东京 · 23:56` / `✓ 未读`）。
- 📊 **悬停穿透轨迹明细**：鼠标悬停在已读标签上，立即浮现按时间倒序排列的详细查阅明细表（第 N 次查看、国家城市归属、具体时间戳）。
- 📌 **点击锁定常驻（Click-to-Pin）**：支持点击标签固定浮窗，自带独立滚动条，轻松翻阅几十条历史轨迹，支持复制与多选。
- ⚡ **写信自动植入**：网页写信界面右下角自动挂载追踪助手，点击“发送”静默注入 1×1 隐形透明追踪像素（Tracking Pixel），不影响正文阅读体验。
- 🛡️ **干净私有信誉**：基于个人独立的 Cloudflare Worker 云端节点，无公共追踪平台共享域名的黑名单污染风险，保障外贸邮件极高送达率。
- 💰 **终身 0 成本**：基于 Cloudflare Workers 免费层（每天 10 万次免费请求额度），无任何隐形消费与水印。

## 部署与安装指南

### 第一步：部署免费云端追踪节点（耗时约 2 分钟）

追踪像素需要一个公网节点来响应收件人打开邮件时的图片请求，并自动解析客户的国家、城市、IP、打开时间：

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)（支持 Google 账号一键登录）。
2. 在左侧菜单点击 **Workers 和 Pages** -> **创建** -> **创建 Worker**。
3. 给 Worker 命名（如 `ali-email-tracker`），点击 **部署**。
4. 部署后点击 **编辑代码**，将本项目 `cloudflare-worker/worker.js` 中的全部代码全选替换进去，点击 **部署 (Deploy)**。
5. **创建并绑定免费 KV 数据库**：
   * 回到 Cloudflare 控制台，点击 **Workers 和 Pages** -> **KV** -> **创建命名空间**，名字填写：`TRACKING_KV`。
   * 回到刚才创建的 Worker，进入 **设置 (Settings)** -> **变量 (Variables)** -> 找到 **KV 命名空间绑定** -> 点击 **添加绑定**。
   * 变量名称（Variable Name）填写：`TRACKING_KV`（全大写），对应的值在下拉框中选择刚才创建的 `TRACKING_KV`，保存即可。
6. 记下你的 Worker 公开网址（形如：`https://ali-email-tracker.yourname.workers.dev`）。

> [!TIP]
> **外贸进阶建议**：Cloudflare 默认的 `*.workers.dev` 域名在海外访问极其稳定流畅。如果你希望国内网络测试也能 100% 直连无阻，可以在该 Worker 的“域和路由”设置里绑定一个你公司的二级域名（如 `track.yourcompany.com`）。

---

### 第二步：安装 Chrome 扩展程序

1. 打开谷歌浏览器，在地址栏输入：`chrome://extensions/` 并按回车。
2. 打开页面右上角的 **“开发者模式”**（Developer mode）开关。
3. 点击左上角的 **“加载已解压的扩展程序”**（Load unpacked）。
4. 选择本项目所在文件夹。
5. 点击浏览器右上角拼图图标，将 **“外贸企业邮箱专属追踪助手”** 图标固定到工具栏。

---

### 第三步：配置与开始使用

1. **设置云端服务地址**：
   * 点击浏览器右上角插件图标 📬。
   * 点击右上角 **⚙️（设置）** 图标，填入第一步获得的 Cloudflare Worker 网址（务必包含 `https://`），点击 **保存**。
2. **在阿里/网易企业邮箱发信**：
   * 打开阿里企业邮箱（`mail.aliyun.com` / `qiye.aliyun.com`）或网易企业邮箱。
   * 点击“写信”，右下角会自动显示 **“⚡ 邮件已读追踪”** 状态条。
   * 正常写信并发送，插件会自动注入追踪码并预登记。
3. **查看追踪反馈**：
   * **已发送列表**：打开“已发送”文件夹，每一封邮件主题前侧会自动展示绿色高亮标签（`✓✓ 已读 X次`）。
   * **查看完整轨迹**：鼠标移动到绿色标签上，或直接点击标签，即可查看完整的查阅时间轴、所在国家与城市明细。
